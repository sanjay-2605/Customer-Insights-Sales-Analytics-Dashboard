# Customer Insights & Sales Analytics Dashboard

## Overview

This project analyzes customer and sales data to generate business insights and visual dashboards. It helps identify:

- Revenue trends
- Customer purchasing behavior
- Best-selling products
- Monthly growth
- KPI metrics

## Technologies Used

- Python
- Pandas
- SQLite
- Matplotlib
- SQL

## Features

- Customer segmentation
- Revenue analysis
- Dashboard visualizations
- SQL-based reporting
- KPI tracking
